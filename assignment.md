# Задание по предмету «Проектирование информационных систем»

Условия перенесены из предоставленного преподавателем файла
«Задание_по_предмету_«Проектирование_информационных_систем».docx».

Необходимо спроектировать концепцию организации, учреждения, предприятия или сервиса,
деятельность которого можно улучшить с помощью информационной системы.

Необходимо:

1. Оформить титульный лист.
2. Кратко описать выбранную предметную область.
3. Описать существующую проблему и обосновать необходимость создания ИС.
4. Сформулировать цель проектируемой информационной системы.
5. Определить тип ИС по двум классификационным признакам и обосновать выбор.
6. Выделить пользователей системы и описать их роли.
7. Описать один основной процесс по схеме «вход - действия - выход».
8. Сформулировать 8-10 функциональных требований.
9. Сформулировать 3-5 нефункциональных требований.
10. Составить диаграмму вариантов использования.
11. Создать 3-5 wireframes ключевых экранов.

Срок: **21.10.2026 включительно**.

Преподаватель: **Калугин Алексей Ильич**.

Выбранная тема: **Концепция информационной системы ветеринарной клиники «ВетЗабота»**.
