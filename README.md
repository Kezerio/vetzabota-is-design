## Состав работы

PDF содержит титульный лист, предметную область и проблему, цель ИС, классификацию по двум признакам, пять ролей, процесс записи на прием, 10 функциональных и 5 нефункциональных требований, UML-диаграмму вариантов использования и пять wireframes.

Ключевые экраны: кабинет владельца, запись на прием, расписание регистратуры, карта пациента и прием, отчет руководителя. Дополнительно описаны основные сущности и архитектура системы, приведена таблица соответствия пунктам задания.

«ВетЗабота» рассматривается как условная организация. Все данные на экранах вымышлены. Численные требования являются критериями будущей приемки. Приложение и его внедрение не заявляются выполненными.

## Сборка PDF

Требуются Python 3.10+, пакет ReportLab и установленные шрифты Times New Roman и Arial.
Шрифты не включены в репозиторий. Скрипт по умолчанию ищет файлы `times.ttf`, `timesbd.ttf`, `arial.ttf`, `arialbd.ttf` в `C:/Windows/Fonts`. Можно задать другую папку переменной `VETZABOTA_FONT_DIR`.

```powershell
python -m pip install -r requirements.txt
python scripts/build_pdf.py
powershell -ExecutionPolicy Bypass -File scripts/render_previews.ps1
```

Для последней команды нужен Poppler (`pdftoppm` в PATH). Скрипт сборки создает PDF и текстовое представление; скрипт предпросмотра сохраняет шесть страниц со схемами в `docs/previews/`.

Промежуточные изображения проверки и исходная лекция не публикуются. Использованные учебные материалы указаны на последней странице PDF.
